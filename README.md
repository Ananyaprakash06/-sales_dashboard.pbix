# Data Professional Survey Dashboard

## Overview
This project is an interactive Power BI dashboard built using survey data collected from data professionals across various industries and countries. The dashboard provides insights into salary trends, job roles, programming language preferences, career satisfaction, and work-life balance.

## Business Problem
Understanding trends in the data industry can help aspiring professionals and organizations make informed decisions regarding career paths, skill development, and workforce expectations.

## Objectives
- Analyze salary distribution across different data-related roles.
- Identify the most popular programming languages among data professionals.
- Evaluate work-life balance and salary satisfaction levels.
- Compare responses across different countries and job titles.
- Present key findings through interactive visualizations.

## Tools & Technologies
- Power BI
- Power Query
- Data Modeling
- DAX
- Microsoft Excel / CSV

## Dashboard Features
- Interactive filters and slicers
- Salary analysis by job role
- Country-wise respondent distribution
- Favorite programming language analysis
- Work-life balance ratings
- Salary satisfaction analysis

## Key Insights
- Data Scientists and Data Engineers reported some of the highest average salaries.
- Python emerged as the most preferred programming language among respondents.
- Work-life balance ratings varied across roles and experience levels.
- Salary satisfaction did not always correlate with higher earnings.
- The survey highlighted diverse career paths within the data industry.
